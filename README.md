# Digital System Design

한동대학교 디지털시스템설계 수업에서 수행한
Verilog HDL 기반 디지털 회로 설계 프로젝트를 정리한 저장소입니다.

기본 조합논리회로부터 Counter, UART, VGA, PS/2 Keyboard 등을
단계적으로 구현했으며, 최종 프로젝트로 FPGA 기반 전자계산기를 제작했습니다.

## Tools
- Verilog HDL
- Vivado
- Nexys A7 FPGA

## Final Project
### FPGA Electronic Calculator

Verilog HDL을 이용하여 입력, 연산, 출력 기능을 구현하고
FPGA 보드에서 동작하는 전자계산기를 설계했습니다.

각 기능을 모듈로 나누어 설계하고, 시뮬레이션을 통해
신호와 동작을 확인하며 오류를 수정했습니다.

## What I Learned
처음에는 여러 모듈이 연결되면서 발생하는 오류를 찾는 것이 어려웠지만,
기능을 작은 단위로 나누어 검증하면서 문제의 원인을 단계적으로 찾는 방법을 배웠습니다.
